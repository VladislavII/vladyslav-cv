# Vladyslav Yeletskyi — CV Landing Page

Personal resume landing page focused on logistics, warehouse and back-office roles.

## Stack
- Semantic HTML
- CSS
- Vanilla JavaScript
- No external dependencies

## Features
- Italian / English language switch
- Responsive layout
- Print / Save as PDF mode
- Accessible navigation and reduced-motion support
- Direct contact links: email, WhatsApp, LinkedIn and GitHub

## Deployment
Designed for GitHub Pages from the `main` branch, repository root.
